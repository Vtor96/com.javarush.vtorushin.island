# Island Simulation - симуляция экосистемы острова

Финальный проект для 2 Модуля «Java Core» для курса JavaRush. 
Модель острова с животными и растениями: животные едят, передвигаются, размножаются и умирают от голода. Симуляция работает в многопоточном режиме.

## Функционал

- Остров 100×20 локаций, каждая со своими животными и растениями.
- 15 видов животных (5 хищников, 10 травоядных) + растения.
- Поведение животных: питание (с учётом вероятности по таблице), перемещение, размножение, смерть от голода.
- Рост растений на каждом такте.
- Многопоточная обработка: scheduled-пул для тактов и статистики, worker-пул для параллельной обработки локаций.
- Статистика по острову в консоль с группировкой по хищникам и травоядным.

## Стек

- Java 17+ (switch expressions, records-ready)
- Стандартная библиотека (java.util.concurrent, java.util)
- Без сторонних зависимостей

## Как запустить

1. Откройте проект в IntelliJ IDEA.
2. Запустите `Main.main()`.
3. Симуляция выполнится 30 секунд, после чего выведет финальное состояние.

## Параметры (в `Settings` и `Species`)

- Размер острова: 100×20
- Макс. растений на клетку: 200
- Для каждого вида: вес, макс. количество на клетку, скорость, норма пищи
- Диета: вероятности поедания между видами

## Особенности реализации

- Все характеристики видов вынесены в `Species` enum — удобно расширять.
- Диета хранится как `EnumMap<Species, Map<Species, Double>>` — быстрый lookup.
- Многопоточность: `ScheduledExecutorService` (2 потока) для тактов и статистики, `ThreadPoolExecutor` (по числу ядер) для обработки локаций.
- `ThreadLocalRandom` для потокобезопасной генерации случайных чисел.
- Растения растут каждый такт, если заполненность клетки ниже 80%.
